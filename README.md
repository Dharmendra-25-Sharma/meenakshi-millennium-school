# Meenakshi Millennium Public School Website

Official responsive website for **Meenakshi Millennium Public School & Preschool**. Built with modern HTML5, CSS3 transitions, Night Mode support, and an interactive Admission Form & Admin Submission Access Portal.

---

## 🌟 Key Features

- 🌙 **Night Mode Toggle**: Built-in dark theme with smooth color morphing & localStorage persistence.
- ⚡ **Smooth Transitions & Scroll Animations**: IntersectionObserver scroll effects and glassmorphism design.
- 📋 **Admission Inquiry Form & Admin Portal**: Interactive form for parents and a staff portal ("Access Forms") to view, manage, and export inquiry records to CSV.
- 🏫 **Campus Photo Gallery**: Lightbox image modal showcasing classrooms, reception, principal room, and activity areas.

## 🚀 How to Host on GitHub Pages (Free Web Hosting)

Follow these simple steps to make your website live on the internet using GitHub Pages:

### Step 1: Initialize Git & Push to GitHub
If you have Git installed, open terminal in this folder and run:

```bash
git init
git add .
git commit -m "Initial commit for Meenakshi Millennium Public School website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/meenakshi-millennium-school.git
git push -u origin main
```

*(Replace `YOUR-USERNAME` and repository name with your GitHub account details).*

---

### Step 2: Enable GitHub Pages

1. Go to your repository on [GitHub](https://github.com).
2. Click on **Settings** (⚙️ tab at the top of your repository).
3. In the left sidebar, click on **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` branch and `/ (root)` folder.
5. Click **Save**.

---

### 🎉 Your Website URL
After 1–2 minutes, GitHub will generate your live website link:
`https://YOUR-USERNAME.github.io/meenakshi-millennium-school/`
